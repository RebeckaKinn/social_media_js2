SOCIAL MEDIA APPLICATION - ASSIGNMENT REQUIREMENTS
==================================================

PROJECT GOAL
------------
Build the front end of a social media application using JavaScript and
Noroff's provided API.

Users must be able to register, log in, browse posts, manage their own posts,
view profiles, and follow or unfollow other users.


NON-NEGOTIABLE TECHNICAL REQUIREMENTS
-------------------------------------
- Language: JavaScript
- Front-end frameworks: Not allowed
  - Do not use React, Vue, Angular, or similar frameworks.
- Modules: Use ES6 modules.
- API: Use Noroff's API, including the Auth, Posts, and Profiles endpoints.
- Documentation:
  - Create a README.md explaining how to install and run the project.
  - Add JSDoc annotations to at least three functions.
- UI and CSS:
  - Include at least a basic, usable interface.
  - Only basic styling is required.
- Formatting:
  - Keep the code consistently formatted.
  - Prettier is recommended.
- Deployment:
  - Deploy the finished application using GitHub Pages, Netlify, or Vercel.
- Code structure:
  - Avoid large files containing many unrelated functions.
  - Create modular and reusable code.


REQUIRED FEATURES
-----------------
[ ] Register a new user on a registration page.
[ ] Log in as a registered user on a login page.
[ ] View all posts on the feed page.
[ ] View a single post by clicking a post in the feed.
[ ] Create a new post.
[ ] Edit posts owned by the logged-in user.
[ ] Delete posts owned by the logged-in user.
[ ] View all posts created by another user.
[ ] Follow another user.
[ ] Unfollow another user.
[ ] Search posts using a search bar.
[ ] View the logged-in user's own profile.


REQUIRED PAGES
--------------
[ ] Login page
[ ] Registration page
[ ] Posts/feed page
[ ] Individual post page
[ ] Logged-in user's profile page
